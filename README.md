# Sign Gesture Recognition using Machine Learning

## Overview
This project focuses on real-time hand sign gesture recognition using
machine learning and computer vision techniques.

## Workflow
- Data collection using webcam
- Feature extraction from hand landmarks
- Model training using Python
- Real-time prediction and text-to-speech output

## Tech Stack
- Python
- OpenCV
- MediaPipe
- Scikit-learn

## Note
Datasets and trained model files are intentionally excluded from this
repository due to size limitations. They are generated locally using
data collection scripts.
